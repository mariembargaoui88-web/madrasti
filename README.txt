# مدرستي — النسخة التجريبية عبر الإنترنت

هذه حزمة مشروع أولية لواجهة عربية متجاوبة، مع ربط اختياري بـ Supabase للحسابات وقاعدة البيانات والتخزين.

## قبل البدء
لا يوجد رابط عام حيّ بعد، لأن المشروع يحتاج إلى إنشاء قاعدة بيانات وحساب استضافة باسمك. لم نضع أي كلمات مرور أو مفاتيح سرية داخل الحزمة.

## 1) إنشاء قاعدة البيانات مجانًا
1. افتحي https://supabase.com وأنشئي حسابًا ومشروعًا جديدًا.
2. من لوحة المشروع افتحي SQL Editor ثم New query.
3. انسخي محتوى `supabase_setup.sql` كاملًا، الصقيه، ثم اضغطي Run.
4. من Project Settings > API انسخي Project URL و anon/public key.
5. افتحي `config.js` واستبدلي:
   - `PASTE_SUPABASE_PROJECT_URL_HERE` بعنوان Project URL
   - `PASTE_SUPABASE_ANON_PUBLIC_KEY_HERE` بمفتاح anon/public فقط.
   لا تضعي `service_role` key في الواجهة أبدًا.

## 2) إعداد تسجيل حسابات المعلّمين
1. في Supabase افتحي Authentication > URL Configuration.
2. بعد نشر الموقع، ضعي رابط الموقع في Site URL وأضيفيه إلى Redirect URLs.
3. في Authentication > Providers تأكدي من تفعيل Email.
4. الحسابات تُنشأ بالبريد الإلكتروني وكلمة المرور. قد يلزم تأكيد البريد حسب إعدادات Supabase.

## 3) نشر الواجهة مجانًا
يمكن نشر ملفات المشروع على Netlify أو Cloudflare Pages أو GitHub Pages. لسهولة الاستخدام:
1. أنشئي مستودعًا خاصًا في GitHub وارفعي ملفات المشروع، أو استخدمي أداة رفع مجلد/ملفات لدى خدمة استضافة تدعم المواقع الثابتة.
2. انشري الموقع واحصلي على رابط HTTPS.
3. أضيفي الرابط إلى إعدادات Authentication في Supabase.
4. افتحي الرابط من هاتف وحاسوب لاختبار الوصول إلى الدروس.

## 4) اختبار التطبيق
- افتحي الموقع، اضغطي «دخول المعلّم»، ثم «إنشاء حساب جديد».
- سجّلي الدخول بعد تأكيد البريد إن طُلب ذلك.
- افتحي فضاء المعلّم وانشري درسًا مع ملف أو رابط.
- افتحي الموقع في نافذة أخرى: ينبغي أن يظهر الدرس المنشور للزوار.

## ملاحظات مهمة
- هذه نسخة أولية؛ لا تحتوي على لوحة إدارة للمؤسسة أو نظام صفوف/رموز دخول للتلاميذ.
- الملفات العامة في bucket يمكن لأي شخص يملك رابطها فتحها؛ لا ترفعي معلومات شخصية أو ملفات حساسة.
- لا تجمعي أسماء التلاميذ أو بياناتهم الشخصية في هذه النسخة.
- لا تنشري بيانات `service_role` أو كلمات المرور في ملفات الموقع.
- المجانية وحدود التخزين/الاستضافة تخضع لشروط الخدمات وقد تتغير.
- `manifest.json` يساعد على تعريف التطبيق كتطبيق ويب، لكن تثبيته كـ PWA يتطلب نشرًا عبر HTTPS؛ الخدمة الحالية تحتاج إلى اختبار بعد النشر.


## تثبيت التطبيق على شاشة الهاتف مثل التطبيقات العادية
بعد نشر الموقع برابط HTTPS:
- افتحي الرابط في Chrome على Android.
- اضغطي على قائمة النقاط الثلاث.
- اختاري "تثبيت التطبيق" أو "إضافة إلى الشاشة الرئيسية" (قد تختلف العبارة حسب الجهاز).
- ستظهر أيقونة "مدرستي" على الشاشة الرئيسية. عند فتحها تعمل في نافذة مستقلة مثل التطبيق.
- هذه نسخة PWA (تطبيق ويب قابل للتثبيت)، وليست APK منشورًا على Play Store.
